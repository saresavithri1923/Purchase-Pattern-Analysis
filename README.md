# Purchase-Pattern-Analysis
Analyzed customer purchasing behaviour and sales trends using Excel, Power BI.Identified frequently purchased products and buying patterns to generate insights for better business decisions.

## Project Overview
Purchase Pattern Analysis is a data analytics project focused on understanding customer purchasing behaviour and identifying frequently purchased products using retail transaction data.

The project analyzes transaction records to discover relationships between products and identify frequently purchased item combinations.

## Objectives
- Analyze retail transaction data.
- Identify frequently purchased products.
- Discover product associations and buying patterns.
- Understand customer purchasing behaviour.
- Generate meaningful business insights.

## Tools & Technologies
- Python
- Orange Data Mining
- Microsoft Power BI
- SQL
- Data Visualization

## Methodology
1. Data collection
2. Data cleaning and preprocessing
3. Transaction analysis
4. Frequent item analysis
5. Data visualization
6. Business insights generation

## Business Benefits
- Understand customer purchasing patterns.
- Identify popular product combinations.
- Support product placement decisions.
- Develop cross-selling strategies.
- Improve business decision-making.

## Conclusion
This project demonstrates how data analytics and visualization can transform retail transaction data into useful business insights.
